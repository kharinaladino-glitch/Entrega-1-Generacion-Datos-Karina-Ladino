# Entrega 1 - Generacion y clasificacion de datos

Proyecto realizado en Java 8 para Eclipse.

## Objetivo
La clase `GenerateInfoFiles` genera los archivos planos que se usaran como entrada en las siguientes entregas del proyecto.

## Metodos solicitados
- `createSalesMenFile(int randomSalesCount, String name, long id)`
- `createProductsFile(int productsCount)`
- `createSalesManInfoFile(int salesmanCount)`

## Archivos que genera
Al ejecutar la clase se crean en la carpeta del proyecto:

- `productos.txt`
- `vendedores.txt`
- Un archivo de ventas por cada vendedor.

## Ejecucion en Eclipse
1. Importar el proyecto en Eclipse.
2. Verificar que se use Java 8.
3. Abrir `GenerateInfoFiles.java`.
4. Ejecutar con `Run As > Java Application`.
5. Revisar los archivos `.txt` creados en la carpeta del proyecto.
